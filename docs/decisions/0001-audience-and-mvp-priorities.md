## Question

Which audience and capability set should anchor the business requirements and first MVP?

## Options considered

2. Engineering-platform showcase with thin analytics.
3. Analytics-first study with a minimal platform.
4. Custom audience or capability selection.

## User selection

The user selected “Analyst-facing monitoring tool with an engineering showcase” and set the priority order to candidate urban expansion, vegetation change, surface-water extent change, broad coastal change, then multi-year environmental indicators. The MVP includes candidate urban expansion and vegetation change.

## Rationale

This records the user's selected audience, priority order, and MVP set. No additional rationale was supplied.
